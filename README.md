# [Caissa](https://caissa.vercel.app/)

Ever since learning to code, I've always wondered if I could implement the logic behind one of my favorite games by myself, without dependencies and libraries. So I sat down one day and started working on Caissa. It took longer than I expected, due to my limited time and the inherent complexities of both chess and responsive design but I got it working. A sample chess application made with React supporting local play on both desktop and mobile devices. I'm still occasionally adding new stuff to this project, so do keep an eye out!

# Rules and Controls

You know chess? Great! Its the same rules. Select a piece and then click on destination. If move is legal, it will be made on the board and turn passes. Enjoy a nice game!

# Features currently

- Fully fledged chess game logic including castling, en passant, promotion etc.
- Game termination logic through checkmate, stalemate, timeout.
- Legal move highlighting for selected piece.
- Navigation and move list supports access to specific board states after certain moves as well as sequentially.
- Includes a proof of concept timed mode which currently supports 5+0 games.
- Responsive layout for mobile screens and desktops.

# Future features

- Custom start positions, more time controls.
- Support for three move repetitions and 50 move rule.
